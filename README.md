# 骑行AI教练

iOS 优先的骑行导航 + AI 教练网页应用。

## 功能

- 🗺️ **高德地图路线规划** — 搜索目的地，规划骑行路线
- 🧭 **在线导航 + 语音播报** — 实时导航指引，锁屏后持续播报
- ❤️ **心率监测** — 蓝牙心率带连接（iOS Safari 16+）
- 🔄 **踏频监测** — 蓝牙踏频器连接 / GPS 速度估算
- 🤖 **AI 教练** — 心率区间分析，实时语音指导加速/减速/踏频调整
- 🔊 **iOS 后台播报** — 锁屏后语音不中断

## 使用前准备

### 1. 获取高德地图 API Key

1. 访问 [高德开放平台](https://lbs.amap.com/)
2. 注册账号 → 创建应用 → 添加 **Web端(JS API)** 类型的 Key
3. 安全密钥设置中填入你的域名（本地测试可用 `localhost`）

### 2. 部署方式

**本地开发：**
```bash
cd cycling-ai
# 用任何静态服务器
python3 -m http.server 8080
# 或
npx serve .
```

**手机访问：**
- iPhone Safari 打开地址
- 分享 → 添加到主屏幕（PWA 安装，获得最佳体验）

### 3. 首次使用

1. 打开应用 → 点击右上角 ⚙️ 设置
2. 填入高德地图 API Key
3. （可选）填入 AI API Key — 用于更智能的教练建议
4. 设置年龄 / 最大心率
5. 保存设置

## iOS 后台保活说明

iOS Safari 对后台网页限制严格。本应用使用以下组合方案：

1. **静音 Audio** — 播放无声循环音频，防止系统挂起页面
2. **Media Session API** — 在锁屏界面显示播放控制
3. **Web Speech API** — 语音播报在后台仍可工作（iOS 15+）

⚠️ **注意：** 如果 iOS 系统内存紧张，仍可能终止页面。建议：
- 骑行时不要打开太多其他应用
- 保持手机充电状态

## 蓝牙传感器兼容性

| 传感器类型 | iOS Safari 16+ | 备注 |
|-----------|----------------|------|
| 心率带 (BLE Heart Rate) | ✅ | 标准 BLE 协议 |
| 踏频器 (CSC) | ✅ | 需支持 Cycling Speed and Cadence |
| 功率计 | ❌ | 暂不支持 |

无蓝牙传感器时，速度通过 GPS 获取，踏频通过齿比估算。

## 心率区间说明

| 区间 | 心率范围 | 状态 | 教练建议 |
|------|---------|------|---------|
| Zone 1 | < 50% max | 恢复 | 加速 |
| Zone 2 | 50-60% | 热身 | 逐步加力 |
| Zone 3 | 60-70% | 🔥 燃脂 | 保持节奏 |
| Zone 4 | 70-80% | 💪 有氧 | 训练效果好 |
| Zone 5 | 80-90% | ⚡ 无氧 | 建议减速 |
| Zone 6 | > 90% | 🚨 极限 | 立即减速 |
